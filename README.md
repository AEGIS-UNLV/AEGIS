## About AEGIS

AEGIS is a Bluetooth Low Energy (BLE) real-time location and security monitoring system designed for environments where personnel safety, equipment tracking, and access control are essential.

Using wireless badges, ESP32 monitoring nodes, and a Raspberry Pi processing hub, AEGIS tracks movement across designated zones and identifies unauthorized access.

A live dashboard displays location information and security alerts, helping operators monitor activity and respond to potential security incidents.
